¿Qué es GDScript?

Es el lenguaje de programación que usa Godot. Es parecido a Python: fácil de leer, con pocas líneas. Todo el juego está escrito en GDScript.

Variables: cajas para guardar datos

variables
var vidas = 5              # Número entero
var nombre = "Rana"        # Texto (String)
var esta_vivo = true      # Booleano (verdadero/falso)
var velocidad = 3.5        # Número decimal (float)

# Con tipo explícito (mejor práctica):
var lives: int = 5
var score: int = 0
var is_active: bool = false
Tip: Las variables con const NO se pueden cambiar: const MAX_LIVES = 5

Funciones: bloques de código reutilizables

funciones
func saludar():
    print("¡Hola!")

func sumar(a, b):
    return a + b  # Devuelve el resultado

func perder_vida(vidas: int) -> int:
    return vidas - 1  "-> int" significa que devuelve un número
En nuestro juego: func die(), func start_game(), func setup_level() son funciones.

Señales: comunicar nodos

1. Definir la señal
signal mi_senal(parametro)

2. Emitir (gritar)
mi_senal.emit(valor)

3. Conectar (escuchar)
otro_nodo.mi_senal.connect(mi_funcion)

4. Función que recibe
func mi_funcion(valor):
    print(valor)

Funciones especiales de Godot

FunciónCuándo se ejecuta
_ready()Cuando el nodo está listo (al inicio)
_process(delta)Cada frame (60 veces por segundo)
_draw()Cuando Godot dibuja el nodo
_on_*Cuando ocurre un evento (botón, señal, etc)
En nuestro juego: _ready() carga highscore, _draw() dibuja el fondo, _on_touch_move() mueve la rana.

Autoload: Singleton global

¿Qué es?
Un script que existe SIEMPRE, en todas las escenas.
Se accede por nombre desde cualquier lugar.

Configurar en Godot:
Project → Project Settings → Autoload
→ Agregar: "GameManager" = "res://scripts/autoload/game_manager.gd"

Usar desde cualquier script:
GameManager.lives          # Leer variable
GameManager.score = 100    # Escribir variable
GameManager.lose_life()    # Llamar función
GameManager.lives_changed.connect(mi_funcion)  # Escuchar señal
En nuestro juego: GameManager es el ÚNICO autoload. Controla todo: vidas, puntos, nivel, música, pausa.

¿Qué es Godot? Básico
▼

Un motor de juegos es...

Imaginate que querés construir una casa. Podrías hacer los ladrillos vos mismo, cortar la madera, fabricar el vidrio... o podrías comprar materiales ya hechos y enfocarte en diseñar la casa.

Un motor de juegos es como tener todos los materiales listos: dibujar imágenes, detectar choques, reproducir sonidos, manejar controles. Vos solo te enfocás en crear el juego.

Godot es gratuito, de código abierto, y es lo que usamos para Croac Crossing.

Los Nodos: las cajitas del juego

En Godot, TODO es un nodo. Un nodo es una cajita que hace UNA cosa específica:

NodoQué haceEn nuestro juego
Node2DContenedor de objetos 2DEl fondo, el nivel
AnimatedSprite2DAnimacionesLa rana caminando/saltando
CharacterBody2DPersonaje con físicaLa rana
Area2DDetecta cuando algo la tocaLos autos
CollisionShape2DForma de choque invisibleRectángulos en rana y autos
AudioStreamPlayerReproduce sonidoSaltos, muerte, música
CanvasLayerCapa encima del juegoHUD, pausa

Las Escenas: rompecabezas de nodos

Una escena es un grupo de nodos juntos. La rana, por ejemplo:

frog.tscn = CharacterBody2D ├── AnimatedSprite2D (sus animaciones) ├── CollisionShape2D (su forma de choque) ├── JumpSound (sonido de salto) ├── DeathSound (sonido de muerte) └── CroakSound (sonido de croac)

Explicación del código

main.gd
extends Node2D    # "Soy un nodo 2D"

var screen_width = 1280  # Ancho en píxeles
var screen_height = 720  # Alto en píxeles

func _draw():
    # Rectángulo: Rect2(x, y, ancho, alto)
    # Color: Color(r, g, b) de 0.0 a 1.0
    draw_rect(Rect2(0, 0, screen_width, 50),
              Color(0.1, 0.1, 0.1))  # Borde oscuro
    draw_rect(Rect2(0, 50, screen_width, 50),
              Color(0.3, 0.7, 0.2))  # Pasto verde
Tip: var crea una variable (una caja para guardar valores). func crea una función (un bloque de código que hace algo).
🔬 Intentalo:

En Godot, abrí main.gd y cambiá los números del Color. Por ejemplo: Color(1, 0, 0) = rojo. ¿Qué pasa?

Las Señales: el concepto MÁS IMPORTANTE 🔊

Las señales son como megáfonos. Uno avisa, otros escuchan:

GameManager dice: "¡PERDÍ UNA VIDA!" ↓ (señal: lives_changed) ↓ HUD escucha → Actualiza "VIDAS: 4" en pantalla ↓ Frog escucha → Se prepara para respawnear
Definir señal
signal lives_changed(new_lives)

Emitir (gritar)
lives_changed.emit(lives)

Escuchar (conectar)
GameManager.lives_changed.connect(_on_lives_changed)
Patrón clave: Definir → Emitir → Conectar → Escuchar

La Rana (frog.gd) Importante
▼

Movimiento por Grilla

La rana NO se mueve libremente. Se mueve de a saltos de 64 píxeles:

↑ (-64 Y) | IZQ ←----+----→ DER | ↓ (+64 Y) Posición: (640, 640) → Salto arriba → (640, 576)
const JUMP_DISTANCE = 64

func _on_touch_move(direction: Vector2):
    var target = position + direction * JUMP_DISTANCE
    target.x = clamp(target.x, 32, 1248)  # No salir
    target.y = clamp(target.y, 32, 688)

Animaciones

La rana tiene 3 hojas de sprites con 4 animaciones cada una:

frog_idle_walk_sheet.png (2×4 frames) ┌────┬────┐ │idle│idle│ Quieta ├────┼────┤ │walk│walk│ Caminando ├────┼────┤ │jump│jump│ Saltando ├────┼────┤ │die │die │ Muriendo └────┴────┘

¿Cómo muere?

func die():
    is_dead = true
    sprite.play("death")        # Animación
    death_sound.play()           # Sonido
    GameManager.lose_life()      # Avisar
    
    # Flash rojo visual
    sprite.modulate = Color(1, 0.3, 0.3)
    
    # Vibrar en celular
    if OS.has_feature("mobile"):
        Input.vibrate_handheld(200)
    
    # Respawnear después de 1 segundo
    await get_tree().create_timer(1.0).timeout
    position = start_position

El Nivel (level.gd) Importante
▼

Cómo se arma un nivel

func setup_level():
    # 1. Obtener dificultad
    var diff = GameManager.get_difficulty()
    var num_lanes = diff.lanes
    
    # 2. Crear spawner por cada carril
    for i in range(num_lanes):
        var spawner = spawner_scene.instantiate()
        spawner.setup(speed, direction, start_y + i * 64)
        add_child(spawner)
    
    # 3. Crear la rana abajo
    var frog = frog_scene.instantiate()
    frog.position = Vector2(640, 640)
    add_child(frog)

Pasar de nivel

Rana llega arriba (zona segura) ↓ GameManager.next_level() → nivel + 1 → +100 puntos → Señal level_changed ↓ level.gd recarga carriles → Nueva dificultad

Flujo del juego

1. ARRANCA → start_screen.tscn (menú)
2. JUGAR → main.tscn (fondo + nodos)
3. GameManager.start_game() → vidas=5, puntos=0
4. Level crea carriles + autos + rana
5. Jugás → teclas → rana salta
6. Chocás auto → die() → lose_life()
7. Llegás arriba → next_level() → más difícil
8. 0 vidas → game_over → menú

Flujo de una función típica

# Cuando la rana choca un auto:

1. auto.gd detecta colisión con frog
    ↓
2. auto llama: frog.die()
    ↓
3. frog.die() ejecuta:
    is_dead = true           # Variable

4. GameManager.lose_life():
    lives -= 1              # Operación
    lives_changed.emit(lives) # Señal
    ↓
5. HUD recibe señal:
